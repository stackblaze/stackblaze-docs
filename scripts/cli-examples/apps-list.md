List the apps in one project, with the environment each one runs in.

```sh
stackblaze apps list -p github-demo-gv35
```

```text
┌──────────────────┬─────────────┬───────┬──────────┐
│ Project          │ Environment │ App   │ Strategy │
├──────────────────┼─────────────┼───────┼──────────┤
│ github-demo-gv35 │ dev         │ nginx │ docker   │
└──────────────────┴─────────────┴───────┴──────────┘
```
