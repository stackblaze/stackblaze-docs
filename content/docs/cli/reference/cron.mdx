## cron run

```text
Usage: stackblaze cron run [options] <name>

Run a scheduled task now (one-off run)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --wait                 Wait until the run finishes (exit 1 if it fails)
                         (default: false)
  --timeout <seconds>    Max --wait time (default: 3600)
  --ci                   Output NDJSON events (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Run a scheduled task now, outside its schedule, and wait for it to finish. With `--wait` the command exits with 1 if the run fails.

```sh
stackblaze cron run nightly-report --wait -p github-demo-cw8z -e dev -a hello-web
```

```text

OK nightly-report succeeded (run hello-web-qw6y-nightly-report-mmww8ro2s)
```

## cron logs

```text
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
```

### Example

Show the output of a scheduled task's runs. Add `-f` to follow a run live, or `--job <run>` for one run.

```sh
stackblaze cron logs nightly-report -p github-demo-cw8z -e dev -a hello-web
```


## cron set

```text
Usage: stackblaze cron set [options] <name>

Create or update a scheduled task (one release)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --schedule <cron>      5-field cron expression, e.g. "0 2 * * *" (UTC), or
                         @hourly / @daily
  --command <cmd>        Command to run in the app image (no shell: use sh -c
                         '…' for pipes)
  --image <image>        Run this image instead of the app's
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Examples:
  stackblaze cron set cleanup --schedule "0 3 * * *" --command "node scripts/cleanup.js"
  stackblaze cron set report --schedule "@hourly" --command "sh -c 'npm run report | tee /tmp/r'"
  stackblaze cron set cleanup --schedule "30 3 * * *"   # change the schedule only
```

### Example

Create a scheduled task that runs every night at 02:00 UTC in the app's image. Use `sh -c '…'` when the command needs a shell.

```sh
stackblaze cron set nightly-report --schedule "0 2 * * *" \
  --command "sh -c 'echo report for \$(date -u +%F); nginx -v'" \
  -p github-demo-cw8z -e dev -a hello-web
```

```text
OK Created nightly-report: 0 2 * * *  sh -c 'echo report for $(date -u +%F); nginx -v'
```

Run it again with only `--schedule` or only `--command` to change just that.

