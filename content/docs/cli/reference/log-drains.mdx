## log-drains add

```text
Usage: stackblaze log-drains add [options] <name>

Add a log drain to the app (one rollout)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --type <sink>          Where the logs go (choices: "quickwit", "syslog",
                         "http", "datadog")
  --endpoint <url>       http(s):// URL, or host:port for syslog (optional for
                         datadog)
  --secret <name>        Name of a Secret in the app's namespace holding the
                         sink credentials (never on the command line)
  --source <name>        Log source, repeatable (default: all of web, worker,
                         build, addons) (choices: "web", "worker", "build",
                         "addons")
  --addon <instance>     With --source addons: only these add-on instances
                         (repeatable)
  --stream <name>        Only this stream (default: both) (choices: "stdout",
                         "stderr", "all")
  --min-level <level>    Drop lines below this level (choices: "debug", "info",
                         "warn", "error")
  --include <regex>      Ship only lines matching this pattern
  --exclude <regex>      Drop lines matching this pattern
  --sample-rate <n>      Keep 1 line in N
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

A drain is saved on the app (spec.logDrains) like the dashboard's Settings →
Log drains does for one app; the server checks the name, sources, sink and
that the endpoint is a public address (platform Quickwit hosts allowed). The
app rolls out with it.

Examples:
  $ stackblaze log-drains add archive --type http --endpoint https://logs.example.com/ingest --secret logs-token
  $ stackblaze log-drains add ops --type syslog --endpoint syslog.example.com:514 --source web --source worker --min-level warn
  $ stackblaze log-drains add dd --type datadog --secret datadog-api-key
May be disabled by your platform admin.
```
