### Example

Show who changed an app recently:

```sh
stackblaze audit -p github-demo-gv35 -e dev -a nginx-9agm -n 3
```

Without `-a` it reads the whole organization's trail. Find the latest deletions:

```sh
stackblaze audit --action delete -n 3
```
