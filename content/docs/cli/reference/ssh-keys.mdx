## ssh-keys add

```text
Usage: stackblaze ssh-keys add [options] [file]

Add a public key (default: ~/.ssh/id_ed25519.pub, id_ecdsa.pub or id_rsa.pub;
"-" reads stdin)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  --name <name>          Key name (default: the key's comment, else user@host)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Add a public key to your account so `stackblaze ssh --native`, `scp` and `sftp` can use it:

```sh
ssh-keygen -q -t ed25519 -f ./laptop-key -N '' -C docs-laptop
stackblaze ssh-keys add laptop-key.pub --name docs-laptop
```

```text
OK Added SSH key docs-laptop (SHA256:5g5mDATXIDsUT/hhNWty4UwZHa24gLT8U4YyaENuOW0)
Connect with: stackblaze ssh --native
```

Without a file, it adds `~/.ssh/id_ed25519.pub` (or `id_ecdsa.pub`, `id_rsa.pub`), and `-` reads the key from stdin.

## ssh-keys remove

```text
Usage: stackblaze ssh-keys remove|rm [options] <key>

Remove a key by ID, fingerprint or name

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Remove a key by its name (its ID or fingerprint work too):

```sh
stackblaze ssh-keys remove docs-laptop
stackblaze ssh-keys list
```

```text
OK Removed SSH key docs-laptop (SHA256:5g5mDATXIDsUT/hhNWty4UwZHa24gLT8U4YyaENuOW0)
No SSH keys on your account. Add one: stackblaze ssh-keys add
```
