```text
Usage: stackblaze deploy [options]

Redeploy the linked app, or ship staged changes with --apply-pending

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  -m, --message <text>   Release message shown in the deployments timeline
  --apply-pending        Apply every staged change (`pending list`) as ONE
                         release (default: false)
  --tag <tag>            Deploy this image tag instead (not with
                         --apply-pending)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Without --apply-pending this is `redeploy` (git apps rebuild, image apps
re-pull) and warns about staged changes it is not shipping.

Examples:
  $ stackblaze variables set FOO=1 --skip-deploy
  $ stackblaze scale web=3 --skip-deploy
  $ stackblaze deploy --apply-pending -m "Bump FOO and scale up"
```
