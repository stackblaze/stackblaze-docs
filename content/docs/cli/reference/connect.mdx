```text
Usage: stackblaze connect [options] [addon]

Open an interactive database shell (psql, mysql, or redis-cli); [addon] =
postgres, mysql or redis, optional when the app has exactly one database addon

Options:
  --api-url <url>       StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>       API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>  Project name
  -e, --env <name>      Environment name (default: production)
  -a, --app <name>      App name
  --instance <name>     Addon instance when multiple match
  --local               Run the client on this machine through a private tunnel
                        (needs psql/mysql/redis-cli installed) (default: false)
  --tunnel              Keep a private tunnel open for GUI tools and print
                        host/port/user/database (default: false)
  --port <port>         Local port for --local/--tunnel (default: a free port)
  --print-only          Open the private tunnel and print its connection string
                        instead of launching a client (tunnel stays open until
                        Ctrl-C) (default: false)
  -h, --help            Print help

Modes:
  stackblaze connect postgres                 psql runs inside the app pod (default)
  stackblaze connect postgres --local         psql runs here, via a private tunnel
  stackblaze connect postgres --local --port 15432 --print-only
                                              print postgresql://…@127.0.0.1:15432/…
  stackblaze connect redis --tunnel           keep 127.0.0.1:<port> open for GUI tools

The tunnel never exposes the database publicly: each local TCP connection is
carried over an authenticated WebSocket to the StackBlaze API, which
port-forwards it to the addon pod. It listens on 127.0.0.1 only, closes after
30 minutes idle, and Ctrl-C closes it. Requires app write access.
--local, --tunnel and --print-only may be disabled by your platform admin.
```

### Example

Open `psql` on your machine against the app's PostgreSQL add-on, through a private tunnel (the app's image has no `psql`, so the default in-pod mode can't be used). Here it creates a table, adds a row and reads it back.

```sh
PAGER=cat PSQL_PAGER=cat stackblaze connect postgres --local -p github-demo-cw8z -e dev -a hello-web
```

