```text
Usage: stackblaze members|member [options] [command]

Organization members, invitations and roles

Options:
  -h, --help                    Print help

Commands:
  list|ls [options]             List members of the current organization and
                                their roles
  invite [options] <email>      Invite someone by email (the invitation link is
                                emailed)
  remove|rm [options] <user>    Remove a member (id, email or username); their
                                account is kept
  role [options] <user> <role>  Change a member's organization-wide role
  roles [options]               List the roles you can assign
  invites [options]             Pending invitations (default: list)
  help [command]                Print this message or the help of the given
                                subcommand(s)
```

## members invites

```text
Usage: stackblaze members invites [options] [command]

Pending invitations (default: list)

Options:
  -h, --help                 Print help

Commands:
  list|ls [options]          List pending invitations (--all: accepted, revoked
                             and expired too)
  revoke [options] <invite>  Revoke a pending invitation (id or email)
  help [command]             Print this message or the help of the given
                             subcommand(s)
```

### members invites list

```text
Usage: stackblaze members invites list|ls [options]

List pending invitations (--all: accepted, revoked and expired too)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  --all                  Include invitations that are no longer pending
                         (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

#### Example

List pending invitations. Here there are none, so `--all` also shows the accepted and revoked ones:

```sh
stackblaze members invites list
```
