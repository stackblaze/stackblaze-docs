```text
Usage: stackblaze export [options]

Write the current projects and apps out as manifests

Options:
  --api-url <url>              StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>              API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                       Output JSON (same as -o json) (default: false)
  --out <dir>                  output directory (default: "stackblaze")
  -p, --project <name>         export a single project
  --all                        keep platform-injected variables in app specs
                               (default: false)
  --reveal, --include-secrets  write environment variable values in plaintext
                               (default: masked as ********, which apply keeps
                               as is) (default: false)
  -o, --output <format>        Output format: text or json (choices: "text",
                               "json")
  -h, --help                   Print help

Variable values (scheduled-task variables too) and basic-auth passwords are
written as ******** unless --reveal is passed (same as `variables list`);
apply/plan treat ******** as "keep the current value".
Shared add-on credentials and registry passwords are masked the same way.
The project's IaC switch (iacEnabled) is not exported: use `projects iac`.

May be disabled by your platform admin.
```
