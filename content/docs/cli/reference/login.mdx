Usage: stackblaze login [options]

Sign in via browser (one-click device login) or --token / --password

Options:
  --json                 Output JSON (same as -o json) (default: false)
  --api-url <url>        StackBlaze API base URL

  --password             Sign in with email and password (supports 2FA)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
