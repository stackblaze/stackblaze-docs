```text
Usage: stackblaze login [options]

Sign in via browser (one-click device login) or --token / --password

Options:
  --json                 Output JSON (same as -o json) (default: false)
  --api-url <url>        StackBlaze API base URL
  --token <token>        API token (sb_pat_... or JWT)
  --browser              Open the one-click sign-in page (default for
                         interactive login)
  --browserless          Print the sign-in URL without opening a browser (SSH /
                         headless)
  --password             Sign in with email and password (supports 2FA)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Sign in on a machine without a browser, such as a CI runner, with an API token:

```sh
stackblaze login --token "$TOKEN"
```

```text

```

Over SSH, `--browserless` prints the sign-in link instead of opening a browser. Open it on any device where you're signed in to the dashboard and choose **Approve**:

```sh
stackblaze login --browserless
```
