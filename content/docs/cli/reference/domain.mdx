## domain add

```text
Usage: stackblaze domain add [options] <host>

Add a custom domain and print the DNS records (TXT + CNAME) to create

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)

                         ready) (default: false)
  --timeout <seconds>    Max --wait time (default: 600)
  --interval <seconds>   Seconds between checks while waiting (default: 10)
  --takeover             The domain is verified by another account that no

                         your TXT record is live and theirs has been gone for
                         consecutive checks (≥10 min) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Add a custom domain to an app. The CLI prints the two DNS records to create at your DNS provider.

```sh
stackblaze domain add shop.example.com -p github-demo-cw8z -e dev -a hello-web
```

## domain verify

```text
Usage: stackblaze domain verify [options] <host>

Check DNS now and advance the domain (DNS records → edge → HTTPS certificate)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --wait                 Keep verifying until the domain is active (HTTPS
                         ready) (default: false)
  --timeout <seconds>    Max --wait time (default: 600)
  --interval <seconds>   Seconds between checks while waiting (default: 10)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Exit code: 0 only when the domain is active (DNS verified and HTTPS ready);
1 while it is still pending (DNS, edge or certificate), on error, or when
--wait times out. The JSON document (--json) is printed either way.
```

### Example

Check a domain's DNS now. Until both records are found it stays pending, and the command exits with 1; add `--wait` to keep checking until HTTPS is ready.

```sh
stackblaze domain verify shop.example.com -p github-demo-cw8z -e dev -a hello-web
```
