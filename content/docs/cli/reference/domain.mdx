```text
Usage: stackblaze domain|domains [options] [command]

Add, verify, list, or remove custom domains for an app

Options:
  --api-url <url>             StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>             API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>        Project name
  -e, --env <name>            Environment name (default: production)
  -a, --app <name>            App name
  --json                      Output JSON (same as -o json) (default: false)
  -o, --output <format>       Output format: text or json (choices: "text",
                              "json")
  -h, --help                  Print help

Commands:
  list|ls [options]           List the app's domains with verification and
                              certificate status
  add [options] <host>        Add a custom domain and print the DNS records
                              (TXT + CNAME) to create
  verify [options] <host>     Check DNS now and advance the domain (DNS records
                              → edge → HTTPS certificate)
  remove|rm [options] <host>  Remove a custom domain (detaches it from the app
                              and its HTTPS certificate)
  status [options] [host]     Show ingress hosts, TLS, and the project wildcard
```

  --interval <seconds>   Seconds between checks while waiting (default: 10)

## domain verify

```text
Usage: stackblaze domain verify [options] <host>

Check DNS now and advance the domain (DNS records → edge → HTTPS certificate)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --wait                 Keep verifying until the domain is active (HTTPS
                         ready) (default: false)
  --timeout <seconds>    Max --wait time (default: 600)
  --interval <seconds>   Seconds between checks while waiting (default: 10)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Exit code: 0 only when the domain is active (DNS verified and HTTPS ready);
1 while it is still pending (DNS, edge or certificate), on error, or when
--wait times out. The JSON document (--json) is printed either way.
```
