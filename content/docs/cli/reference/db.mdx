## db info

```text
Usage: stackblaze db info [options] <instance>

Engine and current CPU / memory / storage of a database add-on

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  --json                 Output JSON (same as -o json) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

The engine and current size of a database add-on, by its instance name:

```sh
stackblaze db info whiteboard-8stj-postgresql-6bt2 -p github-demo-cw8z -e dev
```

```text
whiteboard-8stj-postgresql-6bt2 (PostgreSQL (CloudNativePG))
  cpu:      8
  memory:   32Gi
  storage:  1Gi
```

The JSON also says what can be resized and whether high availability is on:

```sh
stackblaze db info db-qmwu -p import-demo-brkm -e dev --json
```
