```text
Usage: stackblaze proxy|port-forward [options] [local:remote]

Forward a local port to one of the app's ports through a private tunnel
(default: a free local port → the app's http port)

Options:
  --api-url <url>       StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>       API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>  Project name
  -e, --env <name>      Environment name (default: production)
  -a, --app <name>      App name
  -h, --help            Print help

Port spec:
  stackblaze proxy                 free local port → the app's http port
  stackblaze proxy 8080:3000       127.0.0.1:8080 → app port 3000
  stackblaze proxy 3000            same port on both sides
  stackblaze proxy :2222           free local port → app port 2222 (an extra TCP port)

Only the ports the app's own Service exposes are reachable: its http port
(the container port works as an alias) and any extra ports it declares; a
wrong port is refused with the allowed list. Each local TCP connection is
carried over an authenticated WebSocket to the StackBlaze API, which
port-forwards it to a ready pod of the app — nothing is exposed publicly. It
listens on 127.0.0.1 only, closes after 30 minutes idle, and Ctrl-C closes it.
Requires app write access and Console enabled for your organization
(Platform → Console & SSH), like `ssh`.
```
