```text
Usage: stackblaze agent [options] [prompt...]

Chat with the StackBlaze agent (interactive REPL, or one-shot with a prompt)

Options:
  --api-url <url>                 StackBlaze API base URL (env
                                  STACKBLAZE_API_URL)
  --token <token>                 API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --prompt <text>                 send a single prompt and exit (or pass it
                                  positionally)
  --json                          output the final response + tool calls as
                                  JSON (one-shot only) (default: false)
  --plain                         plain text output without enhanced streaming
                                  UI (default: false)
  -y, --yes                       auto-approve destructive tool confirmations
  --list                          list saved agent sessions on this machine
                                  (default: false)
  --thread-id, --session-id <id>  resume a saved agent session
  -a, --app <name>                scope the conversation to an app
  -p, --project <name>            scope the conversation to a project
  -e, --env <name>                scope the conversation to an environment
  -o, --output <format>           Output format: text or json (choices: "text",
                                  "json")
  -h, --help                      Print help
```
