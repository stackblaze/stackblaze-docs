```text
Usage: stackblaze logs [options]

Fetch app logs (live history, --follow stream, or --search)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  -f, --follow           Stream live logs over WebSocket until interrupted
                         (default: false)
  --search               Search durable log store instead of live buffer
                         (default: false)
  -n, --limit <n>        Max lines to show (newest N)
  --minutes <n>          Look-back window for --search
  --container <name>     Container name: web or worker (default web)
  --level <level>        Log level filter for --search
  -q, --query <text>     Full-text query for --search
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```
