## notifications add

```text
Usage: stackblaze notifications add [options] <name>

Add a notification: where to post (--type, --url) and which events (--event,
repeatable)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  --type <kind>          slack, discord or webhook (choices: "slack",
                         "discord", "webhook")
  --url <url>            Incoming webhook URL (Slack / Discord) or your
                         endpoint (webhook)
  --channel <name>       Slack channel to post in
  --secret <value>       Webhook signing secret (webhook type)
  --event <name>         Event to send, repeatable (see `notifications events`)
  --projects <name>      Only events of this project, repeatable or
                         comma-separated (default: all projects)
  --disabled             Create it switched off (default: false)
  --reveal               Echo the URL/secret back in --json output (default:
                         false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Examples:
  $ stackblaze notifications add deploys --type slack --url https://hooks.slack.com/services/… --channel '#deploys' --event deployApp --event rebuildApp
  $ stackblaze notifications add audit --type webhook --url https://ops.example.com/hook --secret "$HOOK_SECRET" --event deleteApp --projects shop
  $ stackblaze notifications events
```
