```text
Usage: stackblaze redeploy [options]

Redeploy the linked app: git apps rebuild, image apps re-pull (or --tag)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --tag <tag>            Deploy this image tag instead
  -m, --message <text>   Release message shown in the deployments timeline
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Re-pull an image app's current tag (for example after the image was rebuilt upstream), with a release message.

```sh
stackblaze redeploy -p github-demo-cw8z -e dev -a hello-web -m "Pick up the patched base image"
```
