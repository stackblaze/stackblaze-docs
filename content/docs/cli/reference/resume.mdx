```text
Usage: stackblaze resume [options]

Resume an app paused with `stackblaze down`

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  -m, --message <text>   Reason, recorded in the deployment history
  --replicas <n>         Older servers without a pause endpoint only: web
                         instances to restore (default 1)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

The app comes back with its saved instance count or autoscaling settings and its
cron jobs re-enabled, running the latest built image.

Examples:
  $ stackblaze resume
  $ stackblaze resume -p shop --phase production -a web
```
