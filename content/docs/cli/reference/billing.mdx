## billing limit

```text
Usage: stackblaze billing limit [options] [amount]

Show or set the on-demand (overage) spending limit: a USD amount per month,
unlimited, or off

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

On-demand spending lets usage beyond the plan's credit keep running and be
billed. "off" stops it at the plan (nothing extra is billed); an amount caps
the extra monthly spend; "unlimited" removes the cap. Turning it on needs a
payment method on file (the server answers 402 otherwise).

Examples:
  $ stackblaze billing limit             # show the current setting
  $ stackblaze billing limit 25          # on, up to $25.00 a month
  $ stackblaze billing limit unlimited
  $ stackblaze billing limit off
```

### billing gpu-credit add

```text
Usage: stackblaze billing gpu-credit add [options] <amount>

Buy GPU credit: prints the payment page for a one-time payment of <amount> USD
and opens it in the browser

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --no-browser           Print the URL only; do not open the default browser
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

<amount> is in USD (25, $25 or 12.50) and is checked against the smallest
and largest top-up the server allows (exit 1 outside them). The credit is
added once the payment completes. Needs a role that may change billing
(exit 3 otherwise). The browser is opened only from a terminal, never with
--json or --no-browser.

Examples:
  $ stackblaze billing gpu-credit              # balance and recent top-ups
  $ stackblaze billing gpu-credit add 25
  $ stackblaze billing gpu-credit add 100 --no-browser --json | jq -r .url
```
