## files mounts

```text
Usage: stackblaze files mounts [options]

List volume mount paths available for file access

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --pod <name>           Target pod (default: primary app pod)
  --container <name>     Target container (default: web)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

May be disabled by your platform admin.
```

### Example

List the paths in the app's pod where you can read and write files: its volumes, plus `/tmp`.

```sh
stackblaze files mounts -p github-demo-cw8z -e dev -a hello-web
```

```text
pod=hello-web-qw6y-web-59ffbdcb4-xckfx  container=web
/data/uploads  pvc=uploads  1Gi
  access: ReadWriteMany
/tmp
```

## files upload

```text
Usage: stackblaze files upload [options] <local>

Upload a local file to a volume mount path

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  --path <path>          Remote file path or directory (trailing / for tar
                         extract dir)
  --extract              Extract tar archive at --path (auto for .tar/.tgz)
  --pod <name>           Target pod
  --container <name>     Target container
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

May be disabled by your platform admin.
```

### Example

Upload a local file into a folder on the app's volume. A trailing `/` on `--path` means "into this folder"; it is created if needed.

```sh
stackblaze files upload customers.csv --path /data/uploads/imports/ -p github-demo-cw8z -e dev -a hello-web
```

```text
OK Uploaded → /data/uploads/imports/customers.csv
pod=hello-web-qw6y-web-59ffbdcb4-xckfx
```
