```text
Usage: stackblaze previews|preview [options] [command]

Manage a project's preview environments (per-branch preview apps)

Options:
  -h, --help                  Print help

Commands:
  list [options]              List the project's preview apps (-e narrows to
                              one environment)
  delete|rm [options] <name>  Delete a preview app and its cloned add-ons (-e
                              when the name exists in several environments)
  enable [options]            Turn preview environments on for the project
                              (pull requests create previews)
  disable [options]           Turn preview environments off for the project
                              (existing previews keep running)
  help [command]              Print this message or the help of the given
                              subcommand(s)
```
