```text
Usage: stackblaze context [options]

Show resolved CLI context (API URL, project, environment, app)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  -p, --project <name>   Project name
  -e, --env <name>       Environment name (default: production)
  -a, --app <name>       App name
  --json                 Output JSON (same as -o json) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help
```

### Example

Show which API, project, environment and app commands in this folder use, and where that came from:

```sh
stackblaze context
```

```text
Context
  api:         https://api-dev.stackblaze.cloud
  project:     github-demo-gv35
  environment: dev
  app:         nginx-9agm
  file:        .stackblaze/project.json
```

Flags override the link for one command. With `--json`:

```sh
stackblaze context --json -a other
```

```text
{

    "app": "other"
  },
  "effectivePhase": "dev",
  "projectFile": ".stackblaze/project.json"
}
```
