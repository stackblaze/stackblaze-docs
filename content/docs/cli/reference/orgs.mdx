## orgs switch

```text
Usage: stackblaze orgs switch [options] <slug>

Switch the saved login to another organization (slug, id or name)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

Saves a token scoped to that organization where `login` saves
credentials. For a single command use the global --org <slug> instead.
A browser-login token is exchanged for a new one in that organization (the
old one is revoked); a password login switches its session. Tokens created
on the dashboard's tokens page are pinned to their organization and cannot
switch: run `login`, or use a token created in that organization.
```
