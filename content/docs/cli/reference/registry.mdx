## registry login

```text
Usage: stackblaze registry login [options] <host>

Save the registry login every app in the organization pulls with (organization
admins)

Options:
  --api-url <url>        StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>        API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --json                 Output JSON (same as -o json) (default: false)
  -u, --username <user>  Registry user name (asked for when left out)
  --password-stdin       Read the password or access token from stdin (default:
                         false)
  -o, --output <format>  Output format: text or json (choices: "text", "json")
  -h, --help             Print help

The password is never a flag (it would land in shell history): it is asked
for without echo, or read from stdin with --password-stdin. It is stored
encrypted and never shown again. One login per organization; saving another
replaces it. Changing the host needs the password again.

Examples:
  stackblaze registry login ghcr.io -u octocat
  echo "$GHCR_TOKEN" | stackblaze registry login ghcr.io -u octocat --password-stdin
  stackblaze registry login docker.io -u acme --password-stdin < token.txt
```

### Example

Save the login every app in the organization uses to pull private images from your registry. Read the password or access token from a file or stdin, so it never lands in shell history:

```sh
stackblaze registry login registry.example.com -u docs-demo --password-stdin < token.txt
```

```text
OK Saved the registry login for registry.example.com (user docs-demo). Apps pull with it from their next start.
```

### Example

Remove the registry login. The CLI asks first:

```sh
stackblaze registry logout
stackblaze registry status
```
