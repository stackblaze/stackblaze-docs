## setup mcp

```text
Usage: stackblaze setup mcp [options]

Configure StackBlaze MCP for Cursor, Claude Code, Codex, VS Code (Copilot),
Windsurf or OpenCode

Options:
  --api-url <url>    StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>    API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --ide <name>       Editor to configure (choices: "cursor", "claude", "codex",
                     "vscode", "windsurf", "opencode", "copilot", default:
                     "cursor")
  --print            Print the config snippet instead of writing the file
                     (token shown as a placeholder) (default: false)
  --mcp-path <path>  Path to a local StackBlaze MCP server script (stdio)
  --force            Use HTTP MCP even if local server is found (default:
                     false)
  -h, --help         Print help

Files (the stackblaze entry is merged in; other servers are kept):
  cursor    ~/.cursor/mcp.json
  claude    ~/.claude.json
  codex     ~/.codex/config.toml            ([mcp_servers.stackblaze])
  vscode    <VS Code user dir>/mcp.json      (alias: copilot)
  windsurf  ~/.codeium/windsurf/mcp_config.json
  opencode  ~/.config/opencode/opencode.json

Examples:
  $ stackblaze setup mcp --ide codex
  $ stackblaze setup mcp --ide vscode --print   # paste into .vscode/mcp.json
```

### Example

Add the StackBlaze MCP server to Cursor. The `stackblaze` entry is merged into `~/.cursor/mcp.json` with your saved token, and other servers in the file are kept:

```sh
stackblaze setup mcp --ide cursor
```

```text
OK Configured stackblaze MCP for Cursor → /tmp/home/.cursor/mcp.json
HTTP transport: https://mcp-dev.stackblaze.cloud/mcp
```

`--print` shows the snippet instead of writing it, with a placeholder for the token:

```sh
stackblaze setup mcp --ide claude --print
```

```text
{
  "mcpServers": {
    "stackblaze": {
      "type": "http",
      "url": "https://mcp-dev.stackblaze.cloud/mcp",
      "headers": {
        "Authorization": "Bearer <STACKBLAZE_TOKEN>"
      }
    }
  }
}
# Claude Code: add this to /tmp/home/.claude.json
# Replace <STACKBLAZE_TOKEN> with an API token (create one: stackblaze tokens create claude-mcp).
```

## setup skills

```text
Options:
  --api-url <url>  StackBlaze API base URL (env STACKBLAZE_API_URL)
```

### Example

Install the StackBlaze skill for Claude Code, so the agent knows how to use the CLI:

```sh
stackblaze setup skills --agent claude
```


## setup agent

```text
  --api-url <url>    StackBlaze API base URL (env STACKBLAZE_API_URL)
```

### Example

Set up every AI coding tool found on this machine in one go: the skill plus the MCP server. Here it found Cursor and Codex:

```sh
stackblaze setup agent
```
