## setup mcp

```text
Usage: stackblaze setup mcp [options]

Configure StackBlaze MCP for Cursor, Claude Code, Codex, VS Code (Copilot),
Windsurf or OpenCode

Options:
  --api-url <url>    StackBlaze API base URL (env STACKBLAZE_API_URL)
  --token <token>    API token, sb_pat_... (env STACKBLAZE_TOKEN)
  --ide <name>       Editor to configure (choices: "cursor", "claude", "codex",
                     "vscode", "windsurf", "opencode", "copilot", default:
                     "cursor")
  --print            Print the config snippet instead of writing the file
                     (token shown as a placeholder) (default: false)
  --mcp-path <path>  Path to a local StackBlaze MCP server script (stdio)
  --force            Use HTTP MCP even if local server is found (default:
                     false)
  -h, --help         Print help

Files (the stackblaze entry is merged in; other servers are kept):
  cursor    ~/.cursor/mcp.json
  claude    ~/.claude.json
  codex     ~/.codex/config.toml            ([mcp_servers.stackblaze])
  vscode    <VS Code user dir>/mcp.json      (alias: copilot)
  windsurf  ~/.codeium/windsurf/mcp_config.json
  opencode  ~/.config/opencode/opencode.json

Examples:
  $ stackblaze setup mcp --ide codex
  $ stackblaze setup mcp --ide vscode --print   # paste into .vscode/mcp.json
```
