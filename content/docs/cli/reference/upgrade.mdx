```text
Usage: stackblaze upgrade [options]

Download and install the latest CLI binary

Options:
  --version <tag>        Specific version (e.g. 0.1.0)
  --channel <name>       Release channel: stable (default) or dev (prereleases
                         from the dev branch)
  --oras                 Pull from ghcr.io via oras instead of GitHub Releases
  --install-path <path>  Target binary path (default: current executable)
  -h, --help             Print help
```

### Example

Update the CLI to the latest stable release. It replaces the binary you ran:

```sh
stackblaze upgrade
```

```text
Target: /tmp/home/bin/stackblaze
OK Already up to date (v1.1.21, latest stable release).
Pass --version 1.1.21 to install that release anyway.
```

Install one release, to another path:

```sh
stackblaze upgrade --version 1.1.21 --install-path /tmp/home/bin/stackblaze
```

```text
Target: /tmp/home/bin/stackblaze
OK Upgraded /tmp/home/bin/stackblaze
Version: 1.1.21
```
