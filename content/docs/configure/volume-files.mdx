---
title: Browse volume files
description: Open a volume in the file browser to see, upload, edit, download and delete its files without a terminal.
---

The file browser shows what's on a [volume](/configure/volumes) and lets you change it from the dashboard.

## Open it

On the canvas, right-click the volume's card (here `data`) and choose **Browse files**. The card's menu also has **Rename** and **Delete**.

<Screenshot id="files/2-menu" alt="The data volume's menu: Browse files, Rename and Delete" />

The file browser opens in a new tab. The header shows the project and environment, and the volume's name with how much of it is used, here **5.0 KB used** of **5.0 GB**.

<Screenshot id="files/3-list" alt="The data volume in the file browser: Search this folder, Refresh, New folder, Upload, and proof.txt" />

Each row has a **Name**, **Size** and **Modified** time. Above the list are **Search this folder** and **Refresh**.

## Create a folder

Click **New folder**, type a name and click **Create**. The dialog says where it's created, here **Created in /**. Click a folder to open it, and **..** to go back up.

<Screenshot id="files/4-new-folder" alt="New folder: a name field, Created in /, Cancel and Create" />

## Upload files

Click **Upload** and pick files, or drop them on an empty folder ("Drop files here or use Upload."). A panel shows each file's progress, then **Uploads finished**.

<Screenshot id="files/5-uploaded" alt="The uploads folder with upload-demo.txt, 20 B, Just now, and Uploads finished at 100%" />

## Open and edit a file

Click a text file to open it in an editor, with **Save** ("Edit the file and save it back to the volume.") and **Close**.

<Screenshot id="files/7-open-file" alt="The editor showing /uploads/upload-demo.txt with its text, Close and Save" />

## File actions

A file's **⋯** menu has **Edit**, **Download**, **Rename**, **Move**, **Duplicate** and **Delete**. A folder's menu has **Rename**, **Move**, **Duplicate** and **Delete**.

<Screenshot id="files/6-actions" alt="A file's menu: Edit, Download, Rename, Move, Duplicate, Delete" />

## Delete

Choose **Delete** in the menu. The browser asks first, for example "Delete uploads? This permanently removes the data from the volume. Folders are deleted with everything inside them." Click **Delete** to confirm.

<Screenshot id="files/8-delete-confirm" alt="Delete uploads? This permanently removes the data from the volume, with Cancel and Delete" />
