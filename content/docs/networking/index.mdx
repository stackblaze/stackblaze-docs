## Redirects

StackBlaze has no redirect rules: there is no redirects file and no redirect setting for a service or a domain. The only redirect it makes is from `http://` to `https://`: a request on plain HTTP gets `308 Permanent Redirect` to the same URL on `https://`.

Every other redirect, such as an old path to a new one, `www` to the root domain, or a single-page app that serves `index.html` for every path, belongs in your app or its web server. For example, this nginx configuration, deployed on dev, sent `/old-page` to `/new-page` with `301`, and answered `/some/client/route` with `index.html`:

```nginx
server {
  listen 8080;
  root /usr/share/nginx/html;
  absolute_redirect off;

  location = /old-page { return 301 /new-page; }

  location / { try_files $uri $uri/ /index.html; }
}
```

Without `absolute_redirect off;`, nginx wrote the redirect as `http://<host>:8080/new-page`: with its own port and plain HTTP, which visitors can't open. With it, the `Location` header is just `/new-page`.
