---
title: Deploy from GitHub
description: Build and deploy an app from a GitHub repository, through the StackBlaze GitHub App or from any public repository URL.
---

This guide deploys [stackblaze/react-vite-starter](https://github.com/stackblaze/react-vite-starter), a small public React app, into a new project. StackBlaze builds it from source.

<Steps>

<Step>

### Add a GitHub repository

In your project, click **+ Service**. The menu lists everything you can add to the environment. Choose **GitHub repository** (**Build and deploy from a repo**).

<Screenshot id="github-opts/1-service-menu" alt="The Add to Dev menu: Template, GitHub repository, Docker image, Database or cache and more" />

</Step>

<Step>

### Pick the repository

**Git repository** lists the repositories the StackBlaze GitHub App can see. The menu on the left switches between the GitHub accounts and organizations you installed the app on. Type to search, then click **Select** next to the repository.

<Screenshot id="github/1-pick" alt="The Git repository dialog, filtered to stackblaze/react-vite-starter, with Select" />

The account menu also has **Use a public repo** (see [below](#deploy-a-public-repository)).

<Screenshot id="github-opts/2-source" alt="The account menu: Use a public repo, then the connected GitHub accounts" />

The gear button next to the search has two items:

- **Refresh** reloads the accounts and repositories.
- **Add org / repositories** opens GitHub's install page for the StackBlaze GitHub App in a popup. There you choose which accounts and repositories the app can access.

<Screenshot id="github-opts/3-gear" alt="The gear menu: Refresh and Add org / repositories" />

</Step>

<Step>

### Review

The app appears on the canvas as **Ready to deploy**. Click the card to open the review panel.

<Screenshot id="github/2-ready" alt="The new app card on the canvas: Ready to deploy" />

<Callout>
Right after you pick a repository, clicking the card can say "Still adding it to the canvas…". Wait a moment and click again.
</Callout>

The review panel shows the repository and what will be deployed:

- **Branch**: the menu next to the repository picks the branch to build. This repository only has `main`.
- **Change** goes back to the repository picker.
- Each app shows its build method and folder, here **Railpack (auto-detect, fast rebuilds) · ./**.
- **Runtime** opens a **start command** (blank keeps the build's default) and the **Port** the app listens on.
- **Configure** opens the app's full settings: variables, build method, build path, autodeploy, visibility, domains and more. See [Service settings](/configure/service-settings).

<Screenshot id="github/3-review" alt="The review panel: repository and branch, the app with Configure, Runtime, and Add another app from this repo" />

<Screenshot id="github-opts/12-branch" alt="The branch menu open, listing main" />

<Screenshot id="github-opts/7-runtime" alt="Runtime open: start command and Port" />

</Step>

<Step>

### Deploy

Click **Deploy**. StackBlaze builds the app from the repository, then starts it. When the card shows **Running**, the card shows its public URL on `stackblaze.app`, with HTTPS.

<Screenshot id="github/5-running" alt="The app card: Running, with its stackblaze.app URL" />

<Screenshot id="github/6-app" alt="The deployed React app in the browser" />

</Step>

</Steps>

## Deploy several apps from one repository

For a monorepo, add one app per folder. In the review panel, click **Add another app from this repo**. **Root Directory** shows the repository's folders; the root is marked **Added** because it is already in this deploy. Pick a folder, or search for one, and click **Add**.

<Screenshot id="github-opts/10-another" alt="Root Directory: the repository's folders, with the root marked Added and src selected" />

## Deploy a public repository

You don't need the GitHub App for a public repository. In the account menu, choose **Use a public repo**, paste the repository's HTTPS URL, such as `https://github.com/stackblaze/react-vite-starter`, and press **Enter**.

<Screenshot id="github-opts/4-public" alt="Public repo: Paste any public HTTPS repository and press Enter" />

The app is added to the canvas as **Ready to deploy**. Click it to open the same review panel, titled **Public git repo**, and deploy it the same way.

<Screenshot id="github-opts/6-review-public" alt="The Public git repo review panel" />
