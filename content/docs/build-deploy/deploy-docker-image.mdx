---
title: Deploy a Docker image
description: Run any public container image from Docker Hub, GitHub Container Registry or another registry.
---

A Docker image service runs a prebuilt container image; nothing is built. For an image in a private registry, first add a [registry login](/security/private-registry). This guide deploys `ghcr.io/nginxinc/nginx-unprivileged:stable-alpine`, an nginx image that listens on port 8080. For the shortest path with Docker Hub's `nginx`, see the [Quick Start](/quickstart).

<Steps>

<Step>

### Add a Docker image

In your project, click **+ Service** and choose **Docker image** (**Run a public or private image**). **Container registry** opens.

<Screenshot id="docker/1-open" alt="Container registry: Search Docker Hub or paste a reference" />

</Step>

<Step>

### Pick the image

You have two ways in:

- **Search Docker Hub**: type a name, such as `redis`. Results appear as you type, with **Official** on official images. Click **Use** next to one. The tag is `latest`.
- **Paste a full reference** from any registry, with its tag, such as `ghcr.io/nginxinc/nginx-unprivileged:stable-alpine`, and press **Enter**. Without a tag, `latest` is used.

<Screenshot id="docker/2-search" alt="Searching Docker Hub for redis: results with Official and Use" />

<Callout>
When you paste a full reference, the list says "Press Enter to use this image reference." Press **Enter** and the reference is used.
</Callout>

</Step>

<Step>

### Review

A card for the image appears on the canvas, **Ready to deploy**. Click it to open the review panel:

- The image and tag, with **Change** to go back to the search.
- Under **Configure applications**, the app with its image. **Runtime** opens a **start command** (blank keeps the image's default) and the **Port**. Set the port your image listens on; it is the port the public URL sends traffic to.
- **Configure** opens the app's settings: variables, visibility (**Public**, **Internal**, **Worker**), custom domains, a pre-deploy command and start command, health checks, basic auth, advanced networking, instances and autoscale, sleep mode, volumes, vulnerability scans, tracing and log retention. See [Service settings](/configure).
- **Add application** adds another app that runs the same image, with its own name, runtime and settings.

<Screenshot id="docker/5-review" alt="The review panel: the image with Change, the app with Configure and Runtime, and Add application" />

<Screenshot id="docker/6-add-app" alt="A second application added from the same image" />

</Step>

<Step>

### Deploy

Click **Deploy**. When the card shows **Running**, it shows the app's public URL on `stackblaze.app`, with HTTPS.

<Screenshot id="docker/10-running" alt="The nginx-unprivileged card: Running, with its URL" />

</Step>

</Steps>
